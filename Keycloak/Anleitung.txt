Vorher im frontend "npm install keycloak-js" ausführen
Um keycloak zu starten einfach "docker compose up -d" in diesem ordner der Konsole ausführen. Alles sollte aufgesetzt sein.
Um keycloak selbst zu konfigurieren kann man über user:admin pass:admin unter localhost:8080 das admin panel öffnen. 
Um änderungen am realm in git hinzuzufügen, "docker-compose run --rm keycloak export --realm EventKC --users same_file --file /opt/keycloak/data/import/EventKC-full-export.json" im ordner ausführen, und den alten realm export mit dem neuen ersetzen.
die User sind 
+-------------------------+
|*username* | *password*  |
|-------------------------|
|test       | test        |
|user       | user        |
|admin      | admin       |
+-------------------------+
bei dem ersten login warden die accounts auch in der datenbank im backend angelegt. 
Um mit token das backend anzusprechen, secureFetch anwenden.
